# 🛵 Тестирование API сервиса "Самокат" (Scooter)

Тесты для API сервиса [Яндекс.Самокат](https://qa-scooter.praktikum-services.ru),  расположенного по адресу:  
🔗 [Документация API](https://qa-scooter.praktikum-services.ru/docs/) 

## 📋 Описание

Этот проект содержит автоматизированные тесты API сервиса "Самокат", написанные на Python с использованием следующих инструментов:

- `pytest` — для запуска и организации тестов
- `requests` — для работы с HTTP-запросами
- `allure-pytest` — для генерации наглядных отчётов

### ✅ Протестировано:
- Создание курьера (`/api/v1/courier`)
- Логин курьера (`/api/v1/courier/login`)
- Создание заказа (`/api/v1/orders`)
- Получение списка заказов (`/api/v1/orders`)

Использована **параметризация** для проверки различных сценариев.

---

## 🧪 Функционал тестов

### 1. **Создание курьера**
- Проверяет, что курьер создаётся с корректными данными.
- Нельзя создать двух одинаковых курьеров.
- Все обязательные поля должны быть переданы.
- Возвращается статус-код `201` при успешном создании.
- При ошибке возвращается статус-код `409` или `400`.

### 2. **Логин курьера**
- Проверяет авторизацию курьера.
- Все обязательные поля должны быть переданы.
- Возвращается `id` курьера при успешной авторизации.
- При неверных данных возвращается ошибка.

### 3. **Создание заказа**
- Можно указать цвет: `BLACK`, `GREY`, оба или не указывать вообще.
- Ответ содержит `track`.
- Используется параметризация для разных вариантов цвета.

### 4. **Получение списка заказов**
- Проверяет, что возвращается список заказов.
- Статус-код ответа — `200`.
